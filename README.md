# Proyecto: Gestión de Personajes de Shingeki no Kyojin

Este proyecto es una aplicación web para gestionar personajes de la serie "Shingeki no Kyojin" (Attack on Titan). Permite crear, editar, eliminar y visualizar personajes, así como generar un PDF con la información de cada uno.

---

## **Requisitos previos**

Antes de comenzar, asegúrate de tener instalado lo siguiente:

1. **PHP**: Versión 7.4 o superior.
2. **MySQL**: Base de datos para almacenar la información de los personajes.
3. **Composer**: Para gestionar dependencias (opcional, si usas librerías externas).
4. **Servidor web**: Apache, Nginx o el servidor integrado de PHP.

# Gestión de Personajes de Shingeki no Kyojin

Esta es una aplicación web para gestionar personajes de la serie "Shingeki no Kyojin" (Attack on Titan). Con esta herramienta, puedes:

- **Crear** nuevos personajes.
- **Editar** la información de personajes existentes.
- **Eliminar** personajes.
- **Generar un PDF** con la información de un personaje.

---

## **Cómo usar el programa**

Sigue estos pasos para utilizar la aplicación:

### 1. **Acceder a la aplicación**
   - Abre tu navegador web (Chrome, Firefox, Edge, etc.).
   - Ingresa la URL donde está alojada la aplicación (por ejemplo, `http://localhost:8000` si la estás ejecutando localmente).

---

### 2. **Ver la lista de personajes**
   - Al acceder a la aplicación, verás una lista de personajes registrados.
   - Cada personaje muestra su nombre, color representativo, tipo, nivel y una foto.
   - También verás opciones para **Editar**, **Eliminar** y **Generar PDF**.

---

### 3. **Crear un nuevo personaje**
   1. Haz clic en el botón **"Crear Personaje"** en la parte superior de la página.
   2. Completa el formulario con los siguientes datos:
      - **Nombre**: Nombre del personaje (ejemplo: "Eren Yeager").
      - **Color Representativo**: Color asociado al personaje (ejemplo: "Verde").
      - **Tipo**: Rol o categoría del personaje (ejemplo: "Soldado").
      - **Nivel**: Nivel de importancia o poder (ejemplo: "10").
      - **Foto (URL)**: Enlace a una imagen del personaje (ejemplo: `https://ejemplo.com/foto.jpg`).
   3. Haz clic en **"Guardar"** para agregar el personaje a la lista.

---

### 4. **Editar un personaje**
   1. En la lista de personajes, haz clic en el botón **"Editar"** junto al personaje que deseas modificar.
   2. Se abrirá un formulario con los datos actuales del personaje.
   3. Modifica los campos que desees.
   4. Haz clic en **"Guardar Cambios"** para actualizar la información.

---

### 5. **Eliminar un personaje**
   1. En la lista de personajes, haz clic en el botón **"Eliminar"** junto al personaje que deseas borrar.
   2. Aparecerá un mensaje de confirmación. Haz clic en **"Aceptar"** para eliminar el personaje.

---

### 6. **Generar un PDF**
   1. En la lista de personajes, haz clic en el botón **"Generar PDF"** junto al personaje deseado.
   2. Se descargará automáticamente un archivo PDF con la siguiente información:
      - Nombre del personaje.
      - Color representativo.
      - Tipo.
      - Nivel.
      - Foto del personaje.

---

## **Preguntas frecuentes (FAQ)**

### **1. ¿Cómo puedo agregar una foto al personaje?**
   - Debes proporcionar una URL válida de una imagen en el campo **"Foto (URL)"** del formulario. Asegúrate de que la URL sea pública y accesible.

### **2. ¿Qué hago si no veo los cambios después de editar un personaje?**
   - Recarga la página para asegurarte de que los cambios se hayan aplicado correctamente.

### **3. ¿Puedo recuperar un personaje eliminado?**
   - No, una vez que eliminas un personaje, no se puede recuperar. Asegúrate de querer eliminarlo antes de confirmar.

### **4. ¿Cómo puedo ver el PDF generado?**
   - El PDF se descargará automáticamente en tu dispositivo. Busca el archivo en la carpeta de descargas de tu navegador.
